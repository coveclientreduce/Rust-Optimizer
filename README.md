# 🏚️ RUST-Optimizer

*Specialized Unity Engine Optimization, Memory Management & Stability Tools for Rust*

---

## 🎮 About the Project

**RUST-Optimizer** is an external utility created for **Rust**, a demanding survival game built on the Unity engine, known for its heavy resource consumption.

The project provides a collection of engine-specific and system-level tools, including garbage collection tweaks, texture streaming optimization, resource allocation management, and other configurable features through an in-game overlay.

## ✨ Features

### 📊 Performance Monitoring

- 🟢 **FPS Tracker** – Real-time frame rate monitoring
- 📏 **Frametime Display** – Track 1% and 0.1% low frametimes
- 🏷️ **Resource Usage** – Display CPU, GPU, and RAM utilization
- 📐 **Network Ping** – Monitor real-time connection latency
- 🎯 **Thermal Tracking** – Keep an eye on hardware temperatures

### 🎨 Engine & Graphics Tuning

- 🎯 **Shader Cache Management** – Optimize compilation and storage
- 🔫 **LOD Optimization** – Adjust level of detail parameters for performance
- ⚡ **Texture Streaming Control** – Adjust pool sizes to reduce stuttering
- 🛡️ **Garbage Collection Tweaks** – Optimize memory allocation cycles

### ⚙️ System & Resource Management

- 🏃 **RAM Cleanup** – Intelligent working set and standby list optimization
- 📍 **CPU Scheduling** – Process priority and core affinity tuning
- 💰 **Power Plans** – Automatic switching to high-performance profiles
- 🔑 **Service Management** – Selective disabling of non-essential background tasks
- 🎮 **Overlay System** – Toggle performance metrics from a convenient interface

## ⚙️ Installation

1. Download the latest archive from the release section.
2. Extract the contents to a separate folder.
3. Start `RustOptimizer.exe` as Administrator.
4. Launch **Rust**.
5. Open the overlay using **INSERT** or **F1**.
6. Configure the required optimization options.
7. Apply settings and restart the game if prompted.

## 🐛 Troubleshooting

### Optimizer does not start

- Make sure you are running `RustOptimizer.exe` as Administrator.
- Check that all files were extracted correctly and not blocked by antivirus.
- Restart the application.

### Overlay does not appear

- Try **INSERT** or **F1**.
- Restart both the optimizer and the game.
- Check whether another overlay (Discord, NVIDIA) is interfering.

### Game crashes or stutters

- Close unnecessary background utilities.
- Restart the game.
- Disable individual optimizations one by one to identify possible conflicts.
- Check whether a recent game update has changed system requirements.
